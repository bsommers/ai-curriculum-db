# Changelog

All notable changes to `ai-curriculum-db` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-07

### Added
- **Initial Release (336 Documents, 355 Semantic Chunks, 1,929 Graph Edges):** Complete OntoLogic-ready knowledge graph and interactive explorer for the 320 unique curated AI/ML papers, 15 area synthesis guides (`curriculum-area-*`), and 1 master learning path guide (`curriculum-kitsumiko-master-path`) adapted from [`kitsumiko/papers`](https://github.com/kitsumiko/papers) under Apache-2.0 (`LICENSE`, `NOTICE.md`, `learning/`, `learning-path.md`, `by-date.md`).
- **Rendered Markdown Artifact Pages (`taxonomy.html`, `chunks.html`, `summary.html`):** Interactive rendered Markdown viewers for **Taxonomy**, **Chunks**, and **Summary MD** with search filtering and **Raw File** + **Download** actions.
- **Neon-Blue `⚡ TRON` Theme (`[data-theme="tron"]`):** 3-way theme selector (`Dark` | `⚡ TRON` | `Light`) across the main dashboard and rendered Markdown pages.
- **Interactive KPI Row & Linked Drawer (`#kpi-linked-drawer`):** Clickable linked document badges and expandable drawer across all 6 KPI cards (`Scoped Documents`, `Semantic Chunks`, `Active Concepts`, `Taxonomy Nodes`, `Total Graph Nodes`, `Total Graph Edges`).
